# Лендинг «Фея Речи»

**Демо: https://hoip32.github.io/feya-rechi-landing/**

Одностраничный лендинг в дизайн-системе основного сайта **fairy-speech.ru**.
Статика без сборки и зависимостей — открывается двойным кликом по `index.html`.

Деплой: GitHub Pages, ветка `main`, корень репозитория. Любой `git push` в `main`
пересобирает сайт автоматически, обычно за минуту.

## Файлы

```
feya-landing/
├── index.html            вся разметка + скрипт (меню, плавный скролл, подсветка раздела,
│                         залипание шапки, маска телефона, форма)
├── assets/
│   ├── style.css         дизайн-система и все стили
│   ├── fonts/            Montserrat + Roboto, подмножества cyrillic и latin (140 КБ)
│   └── img/              фотографии, иллюстрации, логотипы (все .webp)
└── README.md
```

Общий вес — 1,6 МБ, из них первый экран грузит около 200 КБ (остальные картинки в `loading="lazy"`).

## Дизайн-система

Взята с fairy-speech.ru (тема `fairy-of-speech` + настройки Flatsome), задана токенами в `:root`.

| Токен | Значение | Где на основном сайте |
|---|---|---|
| `--brown` | `#673A14` | заголовки, ссылки (`--fs-experimental-link-color`) |
| `--mint` | `#E8F8EA` | фон шапки и секций (`--fs-color-primary`) |
| `--mint-2` / `--mint-3` | `#D8F3DC` / `#B7E4C7` | кружки-номера, кнопки |
| `--pink` | `#FFD6E0` | кнопки `.button-pink` (`--fs-color-secondary`) |
| `--green` | `#627D47` | акцент (`--fs-color-success`) |
| `--ink` | `#333333` | базовый текст (`--fs-color-base`) |
| `--r-card` / `--r-pill` | `50px` / `70px` | скругления карточек и кнопок |
| `--container` | `1350px` | ширина контейнера Flatsome |

Шрифты: **Montserrat** — заголовки, меню, кнопки; **Roboto** — текст. Подвал чёрный — как на основном сайте.

## Что нужно доделать перед публикацией

**1. Подключить форму.** Сейчас форма проверяет поля и показывает «Спасибо», но никуда не отправляет.
В `index.html`, в конце скрипта, есть комментарий `TODO` — замените заглушку на реальную отправку:

```js
fetch('/send.php', { method: 'POST', body: new FormData(form) })
  .then(function(){ form.classList.add('is-sent'); });
```

Либо подставьте шорткод Contact Form 7 вместо `<form class="form" id="form">…</form>`, если ставите лендинг на тот же WordPress.

**2. Проверить цены.** Взяты с fairy-speech.ru/ceny/ на 5 сентября 2026 года. Если прайс менялся — поправьте в секциях «Что мы делаем» и «Цены».

**3. Уточнить два факта в блоке цифр** (секция сразу после первого экрана):
- «15 направлений» — посчитано по меню «Услуги» основного сайта;
- «с 2022 года» — по дате регистрации ИП (ОГРНИП 322470400119693) и первым загрузкам на сайте.

Если у центра есть более точные цифры (сколько детей прошло, сколько специалистов, стаж) — они сработают сильнее.

**4. Убрать запрет индексации.** Демо на GitHub Pages закрыто от поисковиков, чтобы не
дублировать основной сайт. При переносе на боевой домен удалите в `index.html` строку
`<meta name="robots" content="noindex, nofollow">` и файл `robots.txt` целиком.

**5. Не указан режим работы.** На основном сайте его тоже нет, поэтому блока с графиком здесь нет. Если часы появятся — их логично добавить в секцию «Контакты».

## Как устроены шапка, контакты и подвал

**Шапка.** Пункты меню собраны в одну белую капсулу, чтобы не выглядеть семью разбросанными
ссылками. Текущий раздел подсвечивается сам при прокрутке (`aria-current="true"` проставляет
скрипт). При скролле шапка «отрывается» от первого экрана: полупрозрачный фон с размытием,
тень и уменьшенный логотип. Ниже 1180 px меню сворачивается в бургер и открывается белым
скруглённым листом.

**Контакты.** Две карточки филиалов с кнопками «Открыть на карте» (ссылка на Яндекс.Карты
по адресу) и «Позвонить», под ними — белая полоса с телефоном, почтой и соцсетями.
На телефоне карточки встают в столбик, кнопки растягиваются во всю ширину.

**Подвал.** Четыре столбца: логотип с описанием, «Разделы», «Адреса», «Связаться».
На планшете — два столбца, на телефоне — один; навигация везде остаётся вертикальным списком.

## Возможные дополнения

- **Карта.** В «Контактах» вместо ссылок на Яндекс.Карты можно встроить виджет с двумя метками.
- **WhatsApp.** На основном сайте есть QR-код WhatsApp, но прямой ссылки нет — как появится, добавить в блок соцсетей рядом с ВК и Телеграмом (в «Контактах» и в подвале).
- **Ориентиры.** В карточках филиалов есть место под строку «5 минут от метро …» — данных о ближайших станциях у меня не было, поэтому строки нет.
- **Метрика.** Счётчик Яндекс.Метрики и цели на отправку формы не подключены.

## Откуда взяты материалы

- Фотографии центра, портреты специалистов и иллюстрации направлений — с fairy-speech.ru.
- Тексты о центре, преимущества, описание первичной консультации, отзывы, данные лицензии — оттуда же, отредактированы под формат лендинга.
- Фотографии с ornbrg-cmfrt.ru не использованы: это снимки студии английского языка в Оренбурге, к логопедическому центру отношения не имеют. Оттуда взята только структура страницы.
